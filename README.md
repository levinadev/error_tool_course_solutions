## Решения задач курса [Тренажёр по ошибкам в Python](https://stepik.org/a/303724) на Stepik

В репозитории собраны все 89 задач курса на программирование. В файле каждой задачи есть условие и решение, которое проходит проверку на Stepik. Репозиторий нужен, чтобы после решения задачи можно было сравнить свой код с вариантом автора курса.

## Как пользоваться

1. Сначала решите задачу сами и отправьте решение на Stepik.
2. Найдите файл задачи. Он лежит в папке модуля, внутри неё в папке урока и называется `step_NN.py`, где `NN` означает номер шага в уроке.
3. Сравните решения. Если они отличаются, это нормально, у большинства задач несколько правильных решений. Подумайте, чем ваш вариант лучше или хуже.

Если задача не получается, не открывайте решение сразу. Перечитайте теорию урока, запустите код на своих данных, посмотрите комментарии под шагом на Stepik. Подсмотренное решение почти ничему не учит.

## Как запустить решение

Нужен Python 3.10 или новее, сторонние библиотеки не нужны. Решения читают входные данные через `input()`, как на Stepik. Например, так запускается первая задача.

```bash
python 02_how_to_read/02_three_types_of_errors/step_08.py
```

или

```bash
python3 02_how_to_read/02_three_types_of_errors/step_08.py
```

После запуска введите данные с клавиатуры, по одному значению в строке. Пример входных данных есть в начале каждого файла.

## Содержание

Номер модуля в названии папки совпадает с номером модуля в курсе, а номер урока с номером урока внутри модуля.
