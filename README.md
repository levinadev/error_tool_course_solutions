# Решения задач курса [Тренажёр по ошибкам в Python](https://stepik.org/a/303724) на Stepik

В репозитории собраны все 89 задач курса на программирование. В каждой задаче нужно найти и исправить ошибку в готовой программе. В файле задачи есть условие, программа с ошибкой и исправленная версия, которая проходит проверку на Stepik. Репозиторий нужен, чтобы после решения задачи можно было сравнить свой код с вариантом автора курса.

## Как пользоваться

1. Сначала решите задачу сами и отправьте решение на Stepik.
2. Найдите файл задачи. Он лежит в папке модуля, внутри неё в папке урока и называется `step_NN.py`, где `NN` означает номер шага в уроке. Ссылки на все файлы есть в содержании ниже.
3. Сравните своё решение с решением из файла.

Если задача не получается, не открывайте решение сразу. Перечитайте теорию урока, прочитайте сообщение об ошибке снизу вверх, запустите программу на своих данных, посмотрите комментарии под шагом на Stepik. Подсмотренное решение почти ничему не учит.

## Как запустить решение

Нужен Python 3.10 или новее, сторонние библиотеки не нужны. Решения читают входные данные через `input()`, как на Stepik. Например, так запускается первая задача.

```bash
python 02_how_to_read/02_three_types_of_errors/step_08.py
```

или

```bash
python3 02_how_to_read/02_three_types_of_errors/step_08.py
```

После запуска введите данные с клавиатуры, по одному значению в строке. Пример входных данных есть в условии в начале каждого файла.
